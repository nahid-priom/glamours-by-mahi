# Dashboard V3.1 — Design System Notes

## Color

| Token | Value | Use |
|-------|-------|-----|
| Brand pink | `#E11D48` | Active preset, POS feature, links |
| Soft pink fill | `#FFF1F2` | Mobile wash, featured tiles |
| Sales series | `#E11D48` | Chart line |
| Collection series | `#3B82F6` | Chart line |
| KPI tints | rose/green/amber/blue/violet soft gradients | Primary/secondary cards |

## Typography

- KPI amounts: bold, `tabular-nums`, ~1.35–1.5rem primary
- Labels: 11px medium slate-500
- Section titles: 14px semibold

## Spacing / radius

- Cards: `rounded-2xl`, compact `min-h` 72–88px
- Grid gaps: 2–3 (10–12px)
- Content max width: 1366px (layout shell)

## Breakpoints

| Width | Behavior |
|-------|----------|
| < lg | Mobile greeting, 2-col KPIs, stacked charts, compact link rows |
| lg+ | TopHeader greeting only; 4+6 KPI cols; 8+4 charts; 5+4+3 bottom |

## Motion

- Soft hover shadow on cards
- Quick action slight translate on hover
- No heavy decorative animations
